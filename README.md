# Asset borrowing app

A small campus app for borrowing sports equipment. I built both the Flutter app and the Node.js API, so the flow goes from browsing gear on the phone to storing borrow records in the database.

## What it does

- Browse equipment that is actually available
- Submit a borrow request
- Track return status
- Keep inventory and borrow records on the backend

## Stack

- **App:** Flutter
- **API:** Node.js, Express
- **Database:** MySQL

This started as a university project. The repo still has some Flutter boilerplate around it, but the useful bits are in `lib/` (app) and `backend/` (API).
